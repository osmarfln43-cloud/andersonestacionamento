# Migração do sistema de estacionamento

A migração inicial do sistema para uma infraestrutura própria foi iniciada. O backup recebido foi restaurado no novo ambiente, incluindo os dados do aplicativo, as contas de acesso e os arquivos enviados.

O sistema atual continua funcionando enquanto o novo ambiente passa por validação. O Preview da Vercel está disponível para testes; o domínio ainda não foi transferido para a nova versão.

## Pendências antes da publicação

- Testar o acesso com uma conta migrada.
- Revalidar os dados e arquivos em um teste completo do sistema.
- Gerar e importar uma exportação final perto da mudança, para incluir alterações recentes.
- Conferir as configurações de produção e testar o aplicativo no navegador e nos dispositivos usados no estacionamento.
- Planejar a mudança do domínio e confirmar o procedimento de retorno, caso seja necessário.

A mudança para produção só deve ocorrer após essas validações. Até lá, a versão atual permanece ativa.
